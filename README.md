# 重奏引擎 · YuE2 鼓 + 贝斯工程版

把 YuE2 生成的 **Beat 底轨**（无人声）和 ABC 谱，自动合成为一套可直接交付的鼓 + 贝斯工程包。

- 乐器**锁死**：鼓 + 贝斯，不生成旋律、和弦垫、A/B 或镲频变体。
- 每首固定输出 **8 个工程文件**，存放在 `Beat售卖/<英文名>/`。
- 曲名为 5~7 位随机英文名，首字母大写。
- 生成提示词由**回灌链路**驱动（见第三节）；云端生成用 `生成歌曲.py` + `配置/` + `工作流/`。
- 重奏渲染全本地：FluidSynth + 内置 SoundFont，无 GPU、无联网。
- AI 音乐检测实测通过（SubmitHub，**76% 人类创作**，低于平台 85% 阈值）——见第六节。

---

## 一、工程文件

每首歌曲输出：

```text
Beat售卖/<英文名>/
  <英文名>_谱.txt          ABC 谱
  <英文名>_鼓.mid          鼓 MIDI（SoundFont 鼓组，通道 9）
  <英文名>_贝斯.mid        贝斯 MIDI（GM 34 Fingered Bass，program 33，通道 2）
  <英文名>_鼓重奏.wav      鼓重奏轨（与歌曲等长）
  <英文名>_贝斯重奏.wav    贝斯重奏轨（与歌曲等长）
  <英文名>_完整版.wav      原曲 + 鼓 + 贝斯
  <英文名>_高潮版.wav      节奏最强的 24 秒片段
  <英文名>_信息.txt        BPM / 音名 / 调号 / 调式 / 曲风
```

- `完整版` 以原曲 RMS 等响，峰值超过 0.97 时限幅。
- `高潮版` 从 `完整版`（原曲 + 鼓 + 贝斯混音）裁切约 24 秒：**默认按 ABC 谱定位**——谱内 `% chorus` / `% hook` / `% drop` 等段落标记优先，无标记则取小节音符密度最高处；起点吸附小节线。另可传 `--高潮 能量` 改用完整版短时能量扫描，取听感最强的 24 秒。
- 鼓层固定 `-10dB`，贝斯层固定 `-12dB`。

## 三、提示词回灌（防同质化）

生成提示词不是固定文案，而是一条滚动链路：

1. **种子参数**（`启动器.py` 顶部的 `基础参考` 字典）拼出第 1 首的提示词：曲风 / BPM / 调 / 律动 / 质感段；
2. 每首生成完，从返回的 ABC 谱**实测**三个参数并回灌：BPM（`Q:` 头，半速记谱自动翻倍兜底）、拍号（`M:` 头）、调（`K:` 头）；
3. 下一首的提示词用**实测值**拼装，BPM 写成**回灌值 ±5 的区间**，给模型自由度；
4. 曲风与律动谱里读不到（谱只有音符，无音色/鼓组），由提示词链固定传递；
5. **防同质化**：氛围词与点缀词每次从变化池随机取一条（30 次拼装约 14 种措辞），配合工作流侧不锁种子，做到"同类型风格、每首不一样"。

整批跑完，系列会自动向模型"真实听话的程度"收敛（如要求 132 实测总出 128，之后就按 128 要）。

## 四、安装

```bash
# Python 3.10+，Windows / macOS / Linux 均可
pip install -r requirements.txt
```

`音源/` 已内置 `MuseScore_General.sf3` 和 FluidSynth，无需额外安装。

> **关于 Git LFS**：`音源/MuseScore_General.sf3`（38MB）通过 [Git LFS](https://git-lfs.com/) 存储，
> 仓库中只保存一个 133 字节的指针文件。克隆时需确保已安装 Git LFS
> （GitHub Desktop / Git for Windows 默认已包含；Linux 可执行 `apt install git-lfs`）。
> 未安装 LFS 时该文件会是一个指针文本，无法直接使用。

## 五、用法

### 0. 快速开始（推荐）

Windows 下双击 `启动器.bat`（或运行 `python 启动器.py`），按菜单操作：

```text
[1] 生成 Beat（选择云端/本地，输入数量，全自动出完整工程包）
[2] 配置自检（凭据 / 依赖 / 音源）
[0] 退出
```

选择后端（云端 RunningHub / 本地 ComfyUI）和数量即可，其余全自动：回灌提示词拼装（BPM 区间 + 细微变化）→ 生成 Beat 底轨 + ABC 谱 → 谱面实测回灌 → 本地重奏（渲染 + 合成 + 裁高潮）→ 自动命名 → 输出完整工程包到 `Beat售卖/<曲名>/`。

### 1. 生成 Beat 底轨（云端 / 本地）

**生成任务的请求体只上传拼装好的 style**，其余节点、参数一律不动，全部由工作流导出时的默认值负责——任何额外修改（哪怕是空值）都会影响生成结果。任务完成后自动把音频 + ABC 谱下载到输出目录，不做事后校验。

**云端（RunningHub）**——首次使用前，先准备你自己的凭据。API key 和工作流 ID 都是账户私有的——工作流在你账户下，别人的 ID 你调不到，反之亦然：

1. 登录你自己的 RunningHub 账户，把 `工作流/文生音乐带谱_api.json` 导入为工作流；
2. 在网页端**手动成功运行一次**（RunningHub 要求工作流至少手动跑成功一次才对 API 开放）；
3. 从浏览器地址栏复制该工作流的 workflow ID，连同你的 API key 一起填进 `配置/云端配置.json`：

```json
{
  "接口": {
    "api_key": "<你的APIkey>",
    "workflow_id": "<你的工作流ID>"
  }
}
```

**本地（ComfyUI）**——无需 API key，改 `配置/本地配置.json` 里的 ComfyUI 地址（默认 `http://127.0.0.1:8188`），启动 ComfyUI 后即可用。

然后运行：

```bash
python 生成歌曲.py --后端 cloud   # 或 --后端 local
python 生成歌曲.py --后端 cloud --output 输出目录 --style "自定义风格"
```

- 后端默认读 `配置/本地配置.json` 的 `后端` 字段；风格节点映射与轮询参数读 `配置/示例配置.json`。
- 不指定 `--style` 时，使用 `工作流/文生音乐带谱_api.json` 里 27 号节点的默认提示词。
- **把本项目发给别人时**：先清空 `配置/云端配置.json` 里的 api_key 和 workflow_id，让对方按上面步骤填自己的凭据。

### 2. 本地重奏（鼓 + 贝斯）

```bash
python 重奏_鼓贝斯.py <歌曲.mp3/wav/flac> --谱 <ABC乐谱.txt> --输出 Beat售卖/<英文名> --名称 <英文名> --律动 <律动id>
```

示例：

```bash
python 重奏_鼓贝斯.py 歌曲.mp3 --谱 ABC乐谱.txt --输出 Beat售卖/Cliprur --名称 Cliprur --律动 swung
```

- 名称规则：`[A-Z][a-z]{4,6}`，即 5~7 个字母、首字母大写。
- 律动 id 可选（straight/halftime/doublehats/swung/broken/triplet/fourfloor/dembow/poly）；回灌链路下默认 `fourfloor`（对应四踩底鼓）。
- 高潮版定位：`--高潮 谱面`（默认）按 ABC 谱的段落标记 / 音符密度定位，属"结构高潮"；`--高潮 能量` 改用完整版短时能量扫描，取"听感最强"的 24 秒。
- ABC 谱需含和弦符号（引号包裹，如 `"Fm7"`），贝斯按和弦根音演奏；拍号限 4/4。
- 速度以 ABC 的 `Q` 头字段为准（支持 `Q:143` 与 `Q:1/4=143` 两种写法）。

## 六、AI 音乐检测（实测）

本项目产出的音频已用 **SubmitHub AI Song Checker** 实测（免费公开工具，
https://www.submithub.com/ai-song-checker ）：

> 测试样本 `_Zheng3-ban3-g9zkn4m.wav`（2:00）→ 判定 **人类创作，置信度 76%**
> （频谱分析·人类 73%，时间分析·人类 81%，两模型方向一致）

**为什么能过**：SubmitHub 的检测器判断的是"声音像不像 AI 生成的"。本项目的
鼓与贝斯都是**本地真实采样渲染**（FluidSynth + SoundFont，按 4/4 网格与和弦
根音实际演奏），叠加真实的分层动态与 2 分钟时长，落在 SubmitHub 政策里
"AI 作为工具、人类明显参与"的情形。

**阈值背景**：SubmitHub 自 2026-09 起规定，检测分数 **≥85%** 的曲目会被直接
阻止投稿到策展人、且不售卖推广包（纯 AI 与重度处理的混合 AI 同等对待，无申诉
通道）。本项目实测 76%，低于该阈值。

⚠️ **注意**：76% 距阈值仅 9 个百分点，属于安全但不算宽裕；且频谱量化严重的
电子乐是误报高发区。改动鼓型 / 贝斯型 / 混音电平后，建议**重新实测**。
完整测试数据、工具原理与复现步骤见 [`AI检测记录.md`](AI检测记录.md)。

## 七、已知限制

- ABC 半速记谱时 `Q` 可能只有实际 BPM 的一半，鼓/贝斯会随之减半速；需保证谱面 `Q` 与音频一致。
- 鼓型按 4/4 的十六分音符网格生成；非 4/4 会报错。
- 贝斯为固定根音型（1 拍根音、2.5 拍根音、3 拍五度、4 拍高八度），不跟随转位。
- 高潮版默认按 ABC 谱段落标记 / 音符密度定位，是"结构高潮"而非"听感最炸"；谱面无段落标记时退回音符密度，可能与听感不符，需听感最强片段时传 `--高潮 能量`。
- 仓库内置的 FluidSynth 仅为 **Windows x64** 预编译二进制；macOS / Linux 用户需自行安装 FluidSynth，或替换 `音源/fluid/bin/` 下的可执行文件。
